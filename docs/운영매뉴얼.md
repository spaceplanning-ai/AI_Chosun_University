# AI 남도 프리즘 — 전시 운영 매뉴얼

전시장에서 키오스크를 세팅하고 운영하는 분을 위한 문서입니다.
**개발 지식 없이 이 문서만으로 처음부터 끝까지 진행할 수 있도록** 썼습니다.

> 개발·인계 문서는 저장소 루트의 `README.md` 를 보십시오.

---

## 1. 준비물

| 항목 | 비고 |
| --- | --- |
| 세로형 터치 모니터 | 43인치 또는 49인치 (제안서 11.1) |
| 미니 PC 또는 노트북 | Windows 권장. **Node.js 20 이상 설치 필요** |
| 키오스크 꾸러미 폴더 | 개발사에서 전달받은 `kiosk` 폴더 |
| 유선 키보드·마우스 | 세팅용. 관람객에게는 치워 둡니다 |
| 무선 공유기 | **QR 기능을 쓸 때만** 필요 (아래 4장) |

**인터넷 회선은 필요하지 않습니다.** 외부 서버와 통신하지 않습니다.

---

## 2. 설치 — 처음 한 번만

1. 미니 PC에 **Node.js** 를 설치합니다. (https://nodejs.org 의 LTS 버전)
2. 전달받은 `kiosk` 폴더를 바탕화면 등 원하는 위치에 통째로 복사합니다.
3. 폴더 안의 **`키오스크_실행.bat`** 을 더블클릭합니다.
4. 검은 창이 뜨고 잠시 뒤 아래 문구가 나오면 성공입니다.

   ```
   AI 남도 프리즘 키오스크를 시작합니다...
   ```

5. 브라우저를 열고 주소창에 **`http://localhost:3000`** 을 입력합니다.
6. **F11** 을 눌러 전체화면으로 만듭니다.

> **검은 창을 닫으면 키오스크도 꺼집니다.** 전시 중에는 최소화만 하십시오.

### 화면이 글자만 나오고 이상하게 보인다면

꾸러미가 잘못 복사된 경우입니다. 폴더를 **일부만** 복사하면 이렇게 됩니다.
개발사에서 받은 폴더 전체를 다시 복사하십시오.

---

## 3. 전시 당일 아침 점검 (5분)

1. `키오스크_실행.bat` 실행 → 브라우저에서 `http://localhost:3000` → **F11**
2. 대기화면의 **「나만의 여행 만들기」** 를 눌러 5단계를 끝까지 진행
3. 결과화면이 나오면 정상입니다
4. **좌상단 로고를 5번 연속 터치** → 진행자 패널이 열리는지 확인
5. 진행자 패널에서 **「전체화면 키오스크 모드」** 를 눌러 두면 주소창이 사라집니다
6. 진행자 패널을 닫고 **「강제 초기화」** 로 대기화면 복귀

이제 관람객을 받으면 됩니다.

---

## 4. QR 기능을 쓰려면 (선택)

관람객이 일정을 휴대폰으로 가져가려면 **휴대폰이 미니 PC에 접속할 수 있어야** 합니다.

1. 미니 PC와 관람객 휴대폰을 **같은 공유기**에 연결합니다.
2. 미니 PC의 IP 주소를 확인합니다.
   - 검은 창(명령 프롬프트)에서 `ipconfig` 입력 → `IPv4 주소` 항목 (예: `192.168.0.20`)
3. `키오스크_실행.bat` 을 **메모장으로 열어** 아래 줄의 주소를 바꿉니다.

   ```
   set NEXT_PUBLIC_MOBILE_BASE_URL=http://192.168.0.20:3001
   ```

4. 모바일 결과 페이지 서버도 같은 PC에서 함께 띄웁니다(개발사 안내 참조).
5. 키오스크를 다시 실행합니다.

> **이 주소가 틀리면 QR을 찍어도 휴대폰에서 열리지 않습니다.** 전시 시작 전에
> 반드시 본인 휴대폰으로 한 번 찍어 확인하십시오.
>
> QR 기능을 쓰지 않을 예정이면 이 장은 건너뛰어도 됩니다.
> 키오스크의 다른 기능은 모두 정상 동작합니다.

---

## 5. 진행자 패널

**좌상단 로고를 2초 안에 5번 연속 터치**하면 열립니다.
관람객이 우연히 열 수 없도록 숨겨 둔 것입니다.

| 기능 | 설명 |
| --- | --- |
| 전체화면 키오스크 모드 | 브라우저 주소창·탭을 숨깁니다 |
| 강제 초기화 | 지금 화면을 버리고 대기화면으로 돌아갑니다 |
| 대표 시연 시나리오 4종 | 조건 입력을 건너뛰고 결과화면까지 바로 이동합니다 |
| CSV 5종 내려받기 | 연구용 로그 (통계 도구용) |
| XLSX 워크북 내려받기 | 같은 내용을 엑셀 한 파일로 |
| 원본 JSON 내려받기 | 연구자 화면으로 넘길 때 사용 |
| 보관 로그 비우기 | 전시 종료 후 정리용 |

### 시연 시나리오 활용법

관람객이 많아 5단계를 누를 시간이 없을 때, 또는 심사위원께 설명할 때 씁니다.
각 시나리오에는 **무엇을 보여 주는지**가 함께 적혀 있습니다.

| 시나리오 | 보여 주는 것 |
| --- | --- |
| 부모님과 1박 2일 | 보행부담 조건이 후보 선정과 제외에 반영되는 과정 |
| 연인과 감성여행 | 기간이 길수록 초광역 연계지수가 올라가는 양상 |
| 아이와 가족여행 | 아동 동반 조건이 후보 순위를 바꾸는 과정 |
| 비 오는 날 당일여행 | 우천 부적합 자원이 실제로 걸러지는 장면 |

## 6. 관람객 안내 요령 (1분 30초 ~ 2분)

1. **「나만의 여행 만들기」** 를 눌러 주세요
2. 다섯 가지 질문에 답해 주세요 — *하나만 고르는 질문은 누르면 바로 넘어갑니다*
3. AI가 분석하는 과정이 잠시 나옵니다
4. 결과 일정이 나오면 **지도**로 광주와 전남이 어떻게 이어졌는지 보여 주세요
5. 방문지의 **「AI 추천 근거 보기」** 를 눌러 *왜* 골랐는지 보여 주세요
6. **「걷는 시간을 줄여줘」** 를 눌러 일정이 **최소한만** 바뀌는 것을 보여 주세요
7. **「QR로 내 휴대폰에 저장하기」** 로 마무리

### 글씨가 작다고 하시면

화면 **우측 상단의 「큰 글씨로 보기」** 를 눌러 주세요.
글자·버튼·여백이 한꺼번에 커집니다. 다시 누르면 돌아옵니다.

---

## 7. 문제가 생기면

| 증상 | 조치 |
| --- | --- |
| **오류 안내화면이 떴다** | 「처음 화면으로」를 누르면 계속 쓸 수 있습니다. 자주 발생하면 아래 「기술 상세 보기」를 펼쳐 사진을 찍어 개발사에 보내 주십시오 |
| **화면이 멈췄다 / 반응이 없다** | 진행자 패널 → 강제 초기화. 그래도 안 되면 브라우저에서 **Ctrl+R** (새로고침) |
| **앞사람 일정이 그대로 남아 있다** | 정상입니다. 조작이 없으면 자동으로 대기화면으로 돌아갑니다. 급하면 강제 초기화 |
| **QR을 찍어도 안 열린다** | 4장의 IP 주소 설정을 확인하십시오. 휴대폰이 같은 공유기에 연결됐는지도 확인 |
| **글자만 나오고 디자인이 없다** | 꾸러미가 일부만 복사된 것입니다. 폴더 전체를 다시 복사 |
| **검은 창이 닫혔다** | `키오스크_실행.bat` 을 다시 실행하십시오 |
| **전부 안 될 때** | 검은 창 닫기 → `키오스크_실행.bat` 다시 실행 → 브라우저 새로고침 |

> **화면을 껐다 켜는 것으로 해결되지 않는 문제는 없습니다.**
> 데이터는 브라우저에 저장되므로 재시작해도 지금까지의 로그는 남아 있습니다.

## 8. 전시 종료 절차

1. 진행자 패널을 엽니다 (로고 5번 터치)
2. **「XLSX 워크북 내려받기」** 와 **「원본 JSON 내려받기」** 를 눌러 로그를 저장합니다
   - 이 파일이 연구 자료입니다. **반드시 받아 두십시오**
3. 파일을 USB 등 안전한 곳에 복사합니다
4. 다음 전시가 없다면 「보관 로그 비우기」로 정리합니다
5. 브라우저를 닫고 검은 창도 닫습니다

---

## 9. 개인정보에 관하여

관람객이 물어보시면 아래대로 안내하시면 됩니다.

- **이름·연락처·사진을 수집하지 않습니다.**
- 카메라나 마이크를 사용하지 않습니다.
- 저장되는 것은 *어떤 조건을 골랐고 어떤 일정이 나왔는지* 뿐이며,
  개인을 식별할 수 있는 정보와 연결되지 않습니다.
- QR에는 **방문지 목록과 시각만** 담기며, 서버를 거치지 않고 휴대폰에서 바로 열립니다.
- 앱 설치나 회원가입이 필요 없습니다.

---

## 10. 알아 두실 제약

솔직하게 미리 말씀드립니다.

- **관광지 데이터는 시연용 예시입니다.** 운영시간·요금은 실제와 다를 수 있으므로,
  관람객께 "방문 전 공식 출처에서 확인하시라"는 안내가 화면에 함께 나옵니다.
- **이동시간은 좌표 기반 추정치**입니다. 실시간 길찾기가 아닙니다.
- **QR 접속 여부는 기록되지 않습니다.** 키오스크가 오프라인으로 동작하므로
  휴대폰에서 열었는지를 알 방법이 없습니다. 로그의 해당 항목은 항상 '미접속'으로 남습니다.
- 여행일정의 추천 이유는 **점수 계산에서 만들어진 문장**이며, 생성형 AI가 쓴 글이 아닙니다.
  그래서 화면의 설명과 실제 계산이 어긋나지 않습니다.
